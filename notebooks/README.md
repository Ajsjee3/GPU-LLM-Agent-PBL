# 회차별 학습 기록

강의 실습에서 직접 작성하거나 재배포 허가를 받은 코드만 추가합니다. 아래는 정리 계획이며 각 회차의 완료를 의미하지 않습니다.

| 회차 | 주제 | 기록할 내용 |
|---|---|---|
| 01 | GPU 환경 | CUDA, GPU 모델 및 실행 확인 |
| 02 | Transformer | Attention, 토큰 처리 |
| 03 | 오픈소스 LLM | 모델 추론 실습 |
| 04 | 성능 평가 | 응답 시간, VRAM 측정 |
| 05 | 프롬프트 | 입력별 응답 비교 |
| 06 | RAG | 청크, 임베딩, 검색 |
| 07 | LoRA | 학습 설정과 전후 비교 |
| 08 | AI Agent | 도구 선택 및 호출 |
| 09 | FastAPI | API 요청 및 응답 |
| 10 | Web MVP | 실행 화면, 오류 수정 및 평가 |

각 회차별 노트북은 실제 실습 파일을 확보한 뒤 이 폴더에 추가합니다.
